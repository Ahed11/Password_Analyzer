# Password Analyzer

Локальное приложение на Tkinter для анализа паролей и генерации как символьных паролей, так и passphrase.

## Возможности

- анализ длины, состава, энтропии и типовых паттернов;
- словарная проверка по локальному словарю слабых паролей;
- проверка утечек через Have I Been Pwned по модели k-anonymity;
- три сценария оценки перебора: online rate-limited, offline CPU, offline GPU;
- генерация криптографически стойких паролей через `secrets`;
- генерация passphrase из 4-6 случайных слов;
- безопасный UX: скрытие пароля по умолчанию, кнопки показа/скрытия и копирования, автоочистка буфера обмена, предупреждение перед сохранением.

## Запуск

```bash
python main.py
```

## Требования

Проект использует стандартную библиотеку Python. Внешние зависимости не обязательны.

## Словарь слабых паролей

Файл `data/rockyou.txt` считается необязательным. Если он есть, приложение загрузит его один раз и будет переиспользовать из кэша.

Для релизных архивов лучше не вкладывать полный `rockyou.txt` внутрь пакета. Рекомендуемый вариант:

- не включать `data/rockyou.txt` в архив;
- при необходимости положить его рядом вручную после скачивания;
- оставить в архиве только `data/passphrase_words.txt`.

## Замечания по HIBP

Для проверки утечек нужен доступ в интернет. Приложение отправляет только первые 5 символов SHA-1 префикса пароля и не передаёт пароль целиком.
